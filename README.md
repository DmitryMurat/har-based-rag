# har-based-rag

Локальная RAG-система (retrieval-augmented generation) по транскриптам видеоуроков.

## Задача

Собрать единое хранилище знаний по содержимому видеоуроков и уметь задавать по нему вопросы, получая ответы на основе реального содержимого — **без скачивания самих видео**.

Исходные данные — HAR-файлы, полученные через захват сетевых запросов в DevTools браузера во время просмотра урока (видео грузится чанками через сеть; HAR фиксирует эти запросы вместе с телами ответов). Из HAR извлекается только аудиодорожка, которая затем транскрибируется; сам видеофайл нигде не сохраняется.

Требования к решению:
- работать **полностью локально** — ни содержимое уроков, ни какие-либо учётные данные никуда не отправляются в облако (единственное исключение — одноразовая загрузка публичных весов моделей Whisper/эмбеддингов с Hugging Face при первом запуске);
- вопрос-ответ по собранным транскриптам должен работать **офлайн**, без обращения к Claude или другим внешним LLM-сервисам.

Цель — максимально локальное решение: вся обработка (распознавание речи, эмбеддинги, поиск, генерация ответа) выполняется на собственной машине, без внешних облачных API и без необходимости в серверных мощностях.

### Как это работает

1. **HAR → аудио.** `scripts/process_har.py` / `scripts/process.py` разбирают HAR-файл, склеивают сетевые чанки видео по индексу в единый поток и извлекают аудиодорожку через `ffmpeg`. `process.py` — пакетный оркестратор: обрабатывает сразу много HAR-файлов, транскрибация нескольких файлов идёт параллельно (с живыми прогресс-барами).
2. **Аудио → транскрипт.** Аудиодорожка транскрибируется локально через `faster-whisper` (без обращения к внешним API распознавания речи), с подсказкой-словарём терминов (`terms.txt`) для повышения точности на профессиональной лексике.
3. **Автоматический контроль качества.** После каждого успешно транскрибированного файла тихый фоновый проход ищет вероятные ошибки распознавания (смешение кириллицы/латиницы, слова вне `allowlist.txt`, сегменты с низкой уверенностью Whisper) и дописывает кандидатов в карантинный блок `terms.txt` — они не используются как подсказка для Whisper, пока их не подтвердят вручную.
4. **Транскрипты → индекс.** `scripts/build_index.py` строит локальный векторный индекс (ChromaDB) по всем собранным транскриптам, с локальными эмбеддингами (`fastembed`, офлайн после первой загрузки модели).
5. **Вопрос → ответ.** `scripts/ask.py` (консоль) или `web/web.py` (браузер) ищут релевантные фрагменты в индексе и генерируют ответ локальной LLM через Ollama — весь путь от вопроса до ответа не покидает машину.

Исходные `.har` и готовые транскрипты в репозиторий не попадают (см. `.gitignore`) — здесь только код.

## Пререквизиты

Проверено на macOS (Apple Silicon).

### Системные инструменты

- **Python 3.10+**
- **ffmpeg** — извлечение аудиодорожки из склеенных сетевых чанков:
  ```bash
  brew install ffmpeg
  ```
- **Ollama** — локальный LLM-сервер для генерации ответов (`scripts/ask.py`):
  ```bash
  brew install ollama
  brew services start ollama
  ollama pull qwen2.5:7b
  ```
  Модель можно заменить любой другой, поддерживаемой Ollama — см. `scripts/ask.py --model`.

### Python-окружение

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

Ключевые библиотеки: `faster-whisper` (локальная транскрибация), `chromadb` + `fastembed` (локальное векторное хранилище и эмбеддинги), `requests` (обращение к локальному Ollama), `tqdm` (прогресс-бары).

### Браузер

Любой Chromium-based браузер (Chrome, Vivaldi и т.п.) с DevTools для захвата HAR-файлов уроков (Network → Preserve log → Save all as HAR with content).

## Использование

```bash
# Обработать пачку .har-файлов: собрать аудио и транскрибировать
scripts/process.sh --in ~/Downloads --archive ./har_archive --threads 3

# Построить/пересобрать векторный индекс (обычно делает process.sh сам)
./venv/bin/python scripts/build_index.py

# Задать вопрос по собранным транскриптам — полностью офлайн (консоль)
./venv/bin/python scripts/ask.py "ваш вопрос по содержимому уроков"

# То же самое, но в браузере
./venv/bin/python web/web.py
```

Полный список параметров каждого скрипта — флаг `-h`.

## Веб-интерфейс

`web/` — минимальный локальный веб-интерфейс вместо консольного `ask.py`: одно поле для вопроса, ответ и источники на странице.

- Backend (`web/web.py`) — встроенный `http.server`, без Flask и других новых зависимостей; переиспользует ту же логику поиска и генерации ответа, что и `ask.py`.
- Фронтенд (`web/web.html`) — простой HTML + JS без сборки.
- Всё так же полностью локально — ни один запрос не покидает машину.

**Запуск одним кликом:**
- macOS: двойной клик по `web/run_web.command`.
- Windows: двойной клик по `web/run_web.bat`.

Оба скрипта поднимают сервер и сами открывают страницу в браузере по умолчанию. Закрыли вкладку — сервер сам останавливается через несколько секунд (heartbeat-пинги от страницы; активный в моменте запрос не прерывается, даже если генерация ответа долгая).

Вручную: `./venv/bin/python web/web.py [--port 8765]`.

## Словарь терминов и исправление ошибок распознавания

`data/terms.txt` состоит из двух частей:

- **Подтверждённый словарь** (верхняя часть файла) — термины, которые передаются в Whisper как подсказка (`initial_prompt`) и повышают точность распознавания профессиональной лексики.
- **Карантинный блок** (после строки `# === ПОДОЗРИТЕЛЬНЫЕ ТЕРМИНЫ ===`) — кандидаты, найденные автоматически. Whisper их **не видит**. Строки там в формате `термин =>` — допишите правильный вариант после стрелки (`DFIS => дефис`) либо просто удалите строку, если это случайная ошибка распознавания.

Разрешённые английские слова/аббревиатуры, которые не нужно считать подозрительными (`Excel`, `PDF`, `CRM` и т.п.), перечислены в `data/allowlist.txt`.

Когда в карантине накопились разобранные пары `неверное => верное`, применить их к уже готовым транскриптам — **без повторного запуска Whisper**:

```bash
./venv/bin/python scripts/apply_corrections.py
```

Скрипт заменит все вхождения в `transcripts/*.txt`/`*.json`, перенесёт подтверждённый термин в основной словарь, уберёт отработанную строку из карантина и пересоберёт индекс.
